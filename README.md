# Fake Job Posting Detection System

A Machine Learning web application to detect fraudulent job postings using NLP, TF-IDF and Support Vector Machine (SVM).

## Technologies Used
- Python
- Machine Learning
- NLP
- TF-IDF
- SVM
- Scikit-learn
- Streamlit

## Dataset
- 17,880 job postings
- 17,014 genuine postings
- 866 fraudulent postings

## Model Performance
- Accuracy: 98.63%
- Precision: 87.35%
- Recall: 83.82%
- F1 Score: 85.55%
- ROC-AUC: 98.65%

## Run Locally
1. Install dependencies: pip install -r requirements.txt
2. Run: streamlit run app.py
